# R & Python Package for "Robust & Efficient Hypothesis Test for Distribution Shift via Random Forest" 
Conduct hypothesis testing procedure for distribution shift via Comparing the mean of OOB(Out-of-Bag) error and Test Error.

## Benchmark:
