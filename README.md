# R Package for "Robust & Efficient Hypothesis Test for Distribution Shift via Random Forest" 
Conduct hypothesis testing procedure for distribution shift via Comparing the mean of OOB(Out-of-Bag) error and Test Error.

## Benchmark:
### All the benchmark methods are re-implemented in Python.
benchmark_method_stats.py(All of the statistical methods) \\ 
benchmark_method_autotst.py(Auto Machine Learning Two-sample Test)\\

#### Demonstration for the correlation decay after finished fitting many gradient boosting trees: 
simulate_correlation.py 


## Online Extension:
### The online extension for the RFPerm is in onlineExtension\scr\ with the empirical p-value evaluation procedure.
